# endemica

Outbreak intelligence from public health sources. Our submission for the hackIIITD hackathon — Team Prometheus.

endemica reads official outbreak bulletins, pairs every case count with the death toll from the same report, and answers four separate questions about a selected country: is the disease already here, could an infected traveller arrive, could local spread take off, and which country that has not reported yet is most likely to report next.

It never fills a missing input with zero. Every number on screen says whether it was observed, estimated, modelled or a scenario, and a number that cannot be produced says why.

## Running it

```bash
just setup       # dependencies, both halves
just db-up       # PostgreSQL
just db-migrate  # schema
just dev         # API on :8000, web on :5173
```

`just doctor` checks the environment if any of that fails. `just check` runs every gate: format, lint, types, tests.

### Loading data

```bash
just data-fetch        # reference datasets
just data-build        # processed tables
just data-load         # into PostgreSQL
just model-fit         # the gravity model for unobserved passenger flows
just ingest-archive    # WHO Disease Outbreak News, offline and deterministic
just ingest-covid      # WHO's COVID-19 table (Outbreak News does not cover it)
just labels-build      # historical first-report dates
just train-model       # folds, gates, model card, MODEL_EVALUATION.md
```

Two checkouts that disagree can find out why with `just data-fingerprint`, which prints every grounded figure plus the SHA-256 of each live source file.

## What is modelled, and how honest it is about it

The next-country model is a four-parameter complementary log-log survival model, fitted leave-one-outbreak-out on COVID-19 (2020) and mpox (2022) and scored on the pathogen it did not see. It currently serves as `ranking_validated`: the **ordering** passed its held-out gates on both outbreaks, the **absolute level** did not, and the screen says so rather than rounding that distinction away. A gradient-boosted challenger is fitted and scored on the same folds on every training run; it wins inside an outbreak and loses across pathogens, which is why it is recorded and not served.

`MODEL_EVALUATION.md` also records the experiments that failed — destination population, which forecasts better inside an outbreak and worse on a new one; online intercept recalibration, which fixes the level and destroys the ordering — because a model's evaluation is not complete without the alternatives it beat.

## Stack

FastAPI, SQLAlchemy and PostgreSQL behind React 18, TypeScript and Vite. `uv` for Python, `just` as the command interface.
